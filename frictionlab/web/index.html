Know the boundary

Browser isolation alone cannot stop production side effects. Offline snapshot assessment disables website scripts, forms and external services. Fixture agents use a separate disposable application with synthetic data.

Interactive functionality, user journeys, Core Web Vitals and active security tests require a verified local/staging replica, isolated data and integrations, or source access. Unsupported checks are explicitly skipped in offline assessment.

The agent panel and cohort CLI support synthetic journeys on bundled, owned fixtures only.
